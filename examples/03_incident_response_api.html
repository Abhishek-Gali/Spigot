OpsGuard Cloud — Incident & On-Call REST API (v1)

Base URL: https://api.opsguard.dev

Authentication: Send Authorization: Bearer <token> on all requests.

List Monitored Services

GET /v1/services

Returns all production services registered in the OpsGuard on-call catalog.

ParameterLocationTypeRequiredDescription
environmentquerystringnoFilter by deployment environment (prod, staging)

List Active Incidents

GET /v1/incidents

Lists currently triggered or acknowledged production incidents across all on-call rotations.

ParameterLocationTypeRequiredDescription
severityquerystringnoFilter by severity level (sev1, sev2, sev3)
statusquerystringnoFilter by status (triggered, acknowledged, resolved)

Get Incident Details

GET /v1/incidents/{incident_id}

Fetches timeline events, responder assignments, and root-cause tags for a single incident.

ParameterLocationTypeRequiredDescription
incident_idpathstringyesUnique incident identifier (inc_...)

Declare Production Incident

POST /v1/incidents

Pages the active on-call engineer and opens a new incident war-room channel.

FieldLocationTypeRequiredDescription
service_idbodystringyesTarget monitored service identifier
titlebodystringyesConcise incident summary
severitybodystringyesSeverity level (sev1, sev2, sev3)

Delete Test Incident

DELETE /v1/incidents/{incident_id}

Deletes a synthetic or drill incident record from the operational log.

ParameterLocationTypeRequiredDescription
incident_idpathstringyesUnique incident identifier to delete
